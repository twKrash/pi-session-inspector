## Reproducibility of the tarball (corrected)

Packed **content** is reproducible; packed **bytes** are not.

Packing the same commit locally and in CI produced tarballs whose 101 entries are
byte-identical file-for-file — verified by per-file `sha256` over both extracts —
with the same unpacked size (1,393,464 bytes), while the compressed containers
differ (383,272 bytes in CI versus 382,443 locally) because tar/gzip container
metadata varies with the packing environment.

Consequences, recorded rather than smoothed over:

- the registry values above are authoritative for this release, and
  `release-metadata.json` on the GitHub release carries CI's own copy;
- a locally packed tarball's `sha512` is **not** evidence about the published
  artifact; it validates content and file list only;
- an earlier draft of this record claimed that packing the same commit again
  reproduces the identical `sha512`. The CI pack falsified that, and this section
  replaces the claim.
