Qualification of the `1.5.0` publishable artifact — the subagent AgentRun
observability release. Nothing else in this document is publishable.

`release.yml` re-runs the gate suite, packs the tarball, records its SHA-1,
SHA-512 and `release-metadata.json`, inspects the packed contents, and uploads
the artifact on the tag. This record documents the same artifact produced
locally from the release commit, so a reader can compare the two.

**Status: Complete.** Every automated gate below passed on the release commit,
the tarball audit and the clean-machine install passed, and the live
verification recorded below was run against the same code before the release.
